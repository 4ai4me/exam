## 4. 용어 분야 오분류 개선 내역 (승인 반영)

1. **종단저항 (Termination Resistor)**: 히터·온도 $\rightarrow$ **통신·네트워크**
2. **다이오드 (Diode)**: 히터·온도 $\rightarrow$ **기초 전장** (릴레이 역기전력 흡수 및 정류)
3. **바리스터 (Varistor / MOV)**: 히터·온도 $\rightarrow$ **차단기·보호** (서지 흡수)
4. **안전 릴레이 (Safety Relay)**: PLC·I/O $\rightarrow$ **Safety**
5. **EDM (External Device Monitoring)**: UL·NFPA·IEC $\rightarrow$ **Safety**
6. **상호참조 (Cross Reference)**: UL·NFPA·IEC $\rightarrow$ **ECAD·EPLAN·CAD**
7. **페룰 단자 (Ferrule)**: UL·NFPA·IEC $\rightarrow$ **케이블·커넥터**
8. **간헐적 고장 (Intermittent Fault)**: UL·NFPA·IEC $\rightarrow$ **고장진단**
9. **M12 Connector**: 전원 $\rightarrow$ **케이블·커넥터**
10. **Wiring Duct**: 전원 $\rightarrow$ **PANEL 제작·전장작업**
11. **PE (Protective Earth)**: 전원 $\rightarrow$ **EMC·접지**
